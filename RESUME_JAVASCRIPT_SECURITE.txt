  📊 AVANT / APRÈS
═══════════════════════════════════════════════════════════════════════════

  AVANT (Développement - Vulnérable) :
  ────────────────────────────────────────────────────────────────────────
  
  Code source TypeScript :
  ┌─────────────────────────────────────────────────────┐
  │ loadUsers() {                                       │
  │     console.log('API URL:', this.apiUrl);          │
  │     console.log('Token:', this.token);  // ← !     │
  │                                                     │
  │     this.http.get('/api/users').subscribe(         │
  │         data => console.log('Users:', data),       │
  │         err => console.error('Full error:', err)   │
  │     );                                              │
  │ }                                                   │
  └─────────────────────────────────────────────────────┘
  
  JavaScript généré (lisible) :
  ┌─────────────────────────────────────────────────────┐
  │ loadUsers() {                                       │
  │     console.log('API URL:', this.apiUrl);          │
  │     console.log('Token:', this.token);  // VISIBLE!│
  │     // Code lisible avec toute la logique...       │
  │ }                                                   │
  └─────────────────────────────────────────────────────┘
  
  🚨 RISQUES :
     - URLs et endpoints de l'API exposés
     - Tokens potentiellement visibles
     - Détails complets des erreurs
     - Logique métier compréhensible
     - Structure de données visible


  APRÈS (Production - Sécurisé) :
  ────────────────────────────────────────────────────────────────────────
  
  JavaScript généré (obfusqué) :
  ┌─────────────────────────────────────────────────────┐
  │ _0x1a3b(){var _0x4a2b=this;                        │
  │ _0x5c3d[_0x2e1f(0x1a3)](_0x2e1f(0x4b5))            │
  │ [_0x2e1f(0x6c7)](function(_0x8d9){                 │
  │ /* Plus aucun console.log */                       │
  │ /* Code totalement illisible */                    │
  │ /* Chaînes encodées en base64 */                   │
  │ })}                                                 │
  └─────────────────────────────────────────────────────┘
  
  ✅ AVANTAGES :
     - Aucun console.log visible
     - Code complètement obfusqué
     - Chaînes de caractères encodées
     - Variables renommées (_0x1a3b)
     - Logique métier cachée
     - 25% de réduction de taille
