Mode de Réconciliation 1-1

Le mode 1-1 est le mode de réconciliation par défaut qui compare chaque transaction BO avec une transaction partenaire correspondante.

  • Correspondance exacte : Chaque transaction BO doit avoir une transaction partenaire correspondante
  • Critères de matching : Montant, date, référence, etc.
  • Résultat : Transactions matchées, non-matchées et écarts identifiés
