Formatage automatique

💡 Cette option va supprimer une chaîne de caractères spécifique des valeurs sélectionnées.
Toutes les occurrences : "ABC_CM_DEF_CM" → "ABC_DEF"
Au début : "_CM_ABC" → "ABC"
À la fin : "ABC_CM" → "ABC"
💡 Cette option va supprimer tous les chiffres (0-9) des valeurs sélectionnées.
Exemple : "ABC123DEF456" → "ABCDEF"
Exemple : "Téléphone: 0123456789" → "Téléphone: "
💡 Cette option va supprimer les indicatifs téléphoniques selon le type choisi.
International : "+33 1 23 45 67 89" → "1 23 45 67 89"
National français : "01 23 45 67 89" → "1 23 45 67 89"
Personnalisé : Supprime l'indicatif spécifié
Si activé, ne supprime que les décimales qui sont des zéros
💡 Cette option va supprimer la partie décimale des montants.
Avec virgule : "3000,00" → "3000" | "1500,50" → "1500" (si garder valeurs non nulles = false)
Avec point : "3000.00" → "3000" | "1500.50" → "1500" (si garder valeurs non nulles = false)
Option "Garder valeurs non nulles" : "1500,50" reste "1500,50" | "3000,00" → "3000"
Exemple : "774478320" avec 3 digits → "320"
Autres exemples : "1234567890" avec 4 digits → "7890"
Note : Seuls les chiffres sont extraits, les autres caractères sont ignorés
💡 Cette option va supprimer les décimales .0 des valeurs numériques qui représentent des dates.
Exemple : "2024-01-15.0" → "2024-01-15"
Autres exemples : "2023-12-25.0" → "2023-12-25"
Note : Seules les décimales .0 sont supprimées, les autres décimales sont conservées
💡 Cette option va supprimer les espaces selon le type choisi.
Tous les espaces : "A B C" → "ABC"
Espaces en début : " ABC" → "ABC"
Espaces en fin : "ABC " → "ABC"
Espaces multiples : "A B C" → "A B C"
